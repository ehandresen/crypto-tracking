# 💰 Crypto Tracker

Crypto Tracker is a React application that displays live cryptocurrency data using the public [CoinGecko API](https://www.coingecko.com/en/api).

You can search for coins, control how many results are shown, and sort the list using different criteria — all in a clean, responsive UI.

---

## ✨ Features

- Live crypto data from CoinGecko
- Search by **name** or **symbol** (e.g. `BTC`, `Ethereum`)
- Choose how many coins to display (e.g. top 10, 25, 50…)
- Sort by:
  - Market cap (high → low / low → high)
  - Price
  - 24-hour change
- Card layout with:
  - Name + symbol
  - Current price
  - 24h price change (with color)
  - Market cap
- Simple “About” page describing the app
- Responsive design

---

## 🛠 Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- JavaScript (ES6+)
- CSS for styling
- Fetch API for HTTP requests
- [CoinGecko API](https://www.coingecko.com/en/api)
